# The scenario both halves of the crosscheck run: printer.cpp on the plugin's
# own C++, run.mjs on demo/plugin.js's PORT block. Each prints what it computed,
# and crosscheck.sh requires the two printouts to be identical, byte for byte.
#
#   scenario NAME          a heading, printed as is
#   reset EFFECT           the constructor's params[] (EFFECT 0 = SW Cogwheel,
#                          1 = SW Cogwheel Ink), and a crank restarted on Seed
#   preset N               the preset table's row N (1-based) over params[]
#   set ID VALUE           params[ ID ] = VALUE, as a float
#   bpm VALUE              the host's tempo, for Sync's bar modes
#   restart                Crank::Restart( Seed ), as New Sheet does
#   frames N SECONDS       N frames of Resolve + Crank::Advance, every step,
#                          every run and the crank's state printed
#   resolve                every field Resolve() fills, printed
#   displays FULL          GetParameterDisplay for every control while each
#                          control is swept through its range (FULL 0 sweeps
#                          sliders in 21 steps rather than 101, and adds no
#                          Resolve dump per line)
#   clock T T T ...        a fresh Clock fed these host times, in seconds
#
# Ids are the plugin's ParamId numbers (cgtest --list prints them).
